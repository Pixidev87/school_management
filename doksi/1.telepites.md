School Management App – fejlesztési napló

_________Környezet_________

Gép: MacBook (macOS, zsh shell)
Editor: VS Code
Eszközök: PHP, Composer, Node.js, Docker Desktop, MAMP (de a projektnél nem használjuk)


1. Laravel 12 projekt létrehozása_______________________________________________________________________


    bashcurl -s "https://laravel.build/school-management?with=mysql,redis" | bash
    cd school-management

# A parancs létrehozza a Laravel 12 projektet, és beállítja a Docker környezetet MySQL és Redis konténerekkel.


2. Docker konténerek elindítása_______________________________________________________________________

    sail up -d


3. Adatbázis migráció futtatása, az alapértelmezett Laravel táblák létrehozása (sessions, users, stb.):
    
    sail artisan migrate

4. Frontend függőségek telepítése
    
    sail npm install
    sail npm install react react-dom @vitejs/plugin-react
    sail npm install react-router-dom axios
    sail npm install bootstrap @popperjs/core

5. vite.config.js beállítása_______________________________________________________________________


    import { defineConfig } from 'vite';
    import laravel from 'laravel-vite-plugin';
    import react from '@vitejs/plugin-react';

    export default defineConfig({
        plugins: [
            laravel({
                input: ['resources/js/app.jsx'],
                refresh: true,
            }),
            react(),
        ],
    });


6. resources/js/app.js átnevezése app.jsx-re_______________________________________________________________________


    app.js → app.jsx


7. app.jsx beállítása_______________________________________________________________________

    import React from 'react';
    import ReactDOM from 'react-dom/client';
    import 'bootstrap/dist/js/bootstrap.bundle.min.js';
    import '../css/app.css';

    function App() {
        return (
            <div className="container mt-5">
                <h1>School Management App</h1>
            </div>
        );
    }

    ReactDOM.createRoot(document.getElementById('app')).render(<App />);


8. resources/css/app.css beállítása_______________________________________________________________________
    
    @import "bootstrap/dist/css/bootstrap.min.css";


9. resources/views/welcome.blade.php lecserélése_______________________________________________________________________

    <!DOCTYPE html>
    <html lang="hu">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>School Management</title>
        @viteReactRefresh
        @vite(['resources/js/app.jsx'])
    </head>
    <body>
        <div id="app"></div>
    </body>
    </html>


10. Fejlesztői szerver indítása_______________________________________________________________________

    sail npm run dev

11. VÉGEREDMÉNY

    A http://localhost oldalon megjelenik a React app Bootstrap 5 stílussal. A projekt struktúrája:

        school-management/
    ├── app/
    │   ├── Http/
    │   │   └── Controllers/    ← API kontrollerek (később)
    │   └── Models/             ← Adatbázis modellek (később)
    ├── resources/
    │   ├── js/
    │   │   └── app.jsx         ← React belépési pont
    │   └── css/
    │       └── app.css         ← Bootstrap import
    ├── routes/
    │   └── api.php             ← API végpontok (később)
    └── resources/views/
        └── welcome.blade.php   ← egyetlen Blade fájl, betölti a React appot
